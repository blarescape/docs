## 3. Communication & Workspace Alignment
To maintain professional B2+ ESL communication standards and run smooth Agile sprints, we commit to the following working rules:
1. **The Stand-up Standard:** We will arrive prepared for the daily 15-minute stand-up sessions, utilizing the *Past Simple* tense for completed tasks and *Present Perfect* for blocks or ongoing work.
2. **Conflict Resolution & Pushback:** If a technical disagreement arises, we agree to utilize diplomatic language. We will critique architectural ideas, not individuals, by framing feedback with professional softening phrasing (e.g., *"While that approach solves X, I am concerned it might complicate Y"*).
3. **Internal Deadlines:** Team-level draft reviews will occur exactly **24 hours** before the official weekly classroom deliverables are due.
